# Frontend — Carvajal Wishlist (Angular)

Este es el frontend en Angular del proyecto. Para el manual de despliegue
completo (Docker Compose, credenciales, endpoints, etc.) revisa el
`README.md` en la raíz del repositorio (`../README.md`).

## Desarrollo local rápido

```bash
npm install
npm start        # http://localhost:4200
```

Por defecto apunta a los microservicios en `localhost:8081/8082/8083`
(ver `src/environments/environment.ts`).
